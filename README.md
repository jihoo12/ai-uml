# AI UML

A lightweight, dependency-free UML diagram viewer for structured data generated by an AI assistant.

AI writes **JSON or XML** describing actors, use cases, and relationships. AI UML validates the input and renders a **UML use case diagram as SVG** in your browser.

## Quick start

Serve the project over HTTP (ES modules do not reliably load from `file://` URLs). No build step, account, or API key is required.

```sh
python3 -m http.server 8000
```

Open **http://localhost:8000** in a modern browser.

1. Select JSON or XML (or upload a `.json` / `.xml` file).
2. Paste the AI-generated diagram specification.
3. Click **Render diagram**.
4. Export the result with **Download SVG**.

## Generate SVG from a file (CLI)

Node.js 18+ is required. Install the CLI's XML DOM dependency:

```sh
npm install
```

Generate an SVG without opening a browser:

```sh
node cli/generate-svg.mjs examples/order-system.json
node cli/generate-svg.mjs examples/order-system.xml output.svg
```

When the output path is omitted, the file is saved next to the input with an `.svg` extension. You can also stream the SVG to stdout:

```sh
node cli/generate-svg.mjs examples/order-system.json --stdout > output.svg
```

The same renderer powers both the web preview and the CLI, so diagrams have matching layouts. The CLI validates references and safely escapes all labels in its SVG output.

## JSON format

```json
{
  "type": "usecase",
  "title": "Library System",
  "system": "Library",
  "actors": [
    { "id": "member", "name": "Member" },
    { "id": "librarian", "name": "Librarian" }
  ],
  "useCases": [
    { "id": "search", "name": "Search Books" },
    { "id": "borrow", "name": "Borrow Book" },
    { "id": "authenticate", "name": "Authenticate" }
  ],
  "relationships": [
    { "from": "member", "to": "search", "type": "association" },
    { "from": "member", "to": "borrow", "type": "association" },
    { "from": "borrow", "to": "authenticate", "type": "include" },
    { "from": "librarian", "to": "borrow", "type": "association" }
  ]
}
```

## XML format

```xml
<?xml version="1.0" encoding="UTF-8"?>
<diagram type="usecase" title="Library System" system="Library">
  <actors>
    <actor id="member" name="Member" />
    <actor id="librarian" name="Librarian" />
  </actors>
  <useCases>
    <useCase id="search" name="Search Books" />
    <useCase id="borrow" name="Borrow Book" />
    <useCase id="authenticate" name="Authenticate" />
  </useCases>
  <relationships>
    <relationship from="member" to="search" type="association" />
    <relationship from="member" to="borrow" type="association" />
    <relationship from="borrow" to="authenticate" type="include" />
    <relationship from="librarian" to="borrow" type="association" />
  </relationships>
</diagram>
```

## AI prompt

> Generate a UML use case diagram specification in JSON for [describe my system]. Return only valid JSON, following this schema: type must be "usecase"; provide a title and system; actors and useCases are arrays of unique {id, name} objects; relationships is an array of {from, to, type} objects, where type is association, include, extend, or generalization. All from/to values must reference existing IDs.

## Supported features

- UML use case diagrams with actors, system boundary, and labeled use cases
- Association, `<<include>>`, `<<extend>>`, and generalization connections
- JSON and XML input, file upload, sample documents, clear validation messages
- Fully local rendering with downloadable SVG
- No third-party runtime dependencies

The first version uses an automatic column-based layout; it is not yet a general-purpose UML editor. Class, sequence, activity, and other UML diagrams are not yet supported.

## Development

Run the Node.js tests (Node 18+):

```sh
node --test tests/model.test.mjs
```

The application uses native ES modules, so always access it through an HTTP server rather than opening `index.html` directly.

## Security

Input is parsed locally. Labels are inserted through SVG DOM text nodes rather than interpreted as HTML. XML documents containing DTD/entity declarations are rejected. Do not load untrusted SVG exports into privileged contexts without appropriate precautions.
